# Sistema de Reservas de Hotéis

## Descrição do Projeto

Este projeto consiste num sistema de reservas de hotéis que permite aos utilizadores pesquisar e reservar alojamento de forma simples e intuitiva.

A aplicação disponibiliza um sistema de autenticação onde o utilizador pode criar uma conta ou iniciar sessão caso já possua uma. Após o login, o utilizador pode selecionar o hotel pretendido, escolher um ou mais quartos, definir as datas de entrada e saída, selecionar o regime alimentar e confirmar a reserva.

O sistema permite ainda consultar e cancelar reservas efetuadas anteriormente, proporcionando uma gestão simples e eficiente das mesmas.

## Funcionalidades

- Registo de novos utilizadores.
- Login de utilizadores registados.
- Seleção de hotéis disponíveis.
- Escolha de um ou mais quartos.
- Definição das datas de estadia.
- Seleção do regime alimentar.
- Confirmação da reserva.
- Consulta de reservas.
- Cancelamento de reservas.

## Instruções Relevantes

- O utilizador deve criar uma conta antes de efetuar uma reserva. Caso já esteja registado, basta iniciar sessão.
- Apenas utilizadores autenticados podem criar ou cancelar reservas.
- Para efetuar uma reserva é necessário selecionar um hotel, um ou mais quartos, as datas de estadia e o regime alimentar.
- Após a confirmação, a reserva fica associada à conta do utilizador.
- As reservas podem ser consultadas e canceladas através da área do utilizador.
- Recomenda-se a utilização de datas válidas e a verificação da disponibilidade dos quartos antes da confirmação da reserva.

## Objetivo

O objetivo deste projeto é desenvolver um site que facilite a gestão de reservas de hotéis, permitindo aos utilizadores realizar todo o processo de reserva de forma simples, rápida e organizada.
